# /assets/icons

Reserved for favicon and any custom SVG/PNG icons (e.g. `favicon.ico`, `apple-touch-icon.png`).

Currently the header/hero use inline SVGs directly in `index.html` (clock and phone icons) so no icon files are required yet. Add a favicon here and link it from `index.html`'s `<head>` when ready:

```html
<link rel="icon" href="assets/icons/favicon.ico">
```
